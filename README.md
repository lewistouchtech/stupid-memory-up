## 模块概述

三代理验证模块通过并行调用 3 个独立代理对记忆内容进行验证、评分和仲裁，确保记忆存储的准确性和可靠性。

## 核心组件

### 1. 模型连接配置 (`configs/`)
- `omlx_config.py` - OMLX 本地模型连接
- `cloud_models_config.py` - 云端模型配置

### 2. Prompt 模板 (`prompts/`)
- `validator_prompt.txt` - 验证代理 Prompt
- `scorer_prompt.txt` - 评分代理 Prompt
- `arbiter_prompt.txt` - 仲裁代理 Prompt

### 3. 核心处理 (`core/`)
- `triple_agent_processor.py` - 三代理并行处理
- `vote_aggregator.py` - 投票聚合逻辑
- `llm_arbiter.py` - 大模型仲裁
- `mem0_integration.py` - Mem0 存储集成

### 4. 测试 (`tests/`)
- `test_triple_agent.py` - 单元测试
- `test_integration.py` - 集成测试

---

## 工作流程

1. **输入**: 待存储的记忆内容
2. **并行验证**: 3 个代理独立分析
3. **投票聚合**: 
   - 3:0 或 2:1 → 直接采纳多数意见
   - 1:1:1 或争议大 → 触发仲裁
4. **仲裁**: 第四个大模型进行最终裁决
5. **存储**: 写入 Mem0 数据库
